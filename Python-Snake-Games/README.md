🐍 Snake Game

A simple and interactive Snake Game built using Python and Pygame.
This project was created to practice Python programming concepts such as loops, conditions, functions, lists, keyboard events, collision detection, and game development basics.

🎮 Features
🐍 Classic Snake movement
⌨️ Arrow-key controls
🍎 Random food generation
🚫 Food does not appear inside the snake
📈 Score counter
🧱 Wall collision detection
💥 Self-collision detection
📏 Snake grows after eating food
🔄 Restart game using R
🏁 Game Over screen
🏆 Final Score display
👀 Snake head with eyes
🔵 Blue snake theme
🛠️ Technologies Used
Python
Pygame
Random module

⚙️ Installation

1. Clone the repository
   git clone YOUR_GITHUB_REPOSITORY_URL
2. Open the project folder
   cd Snake-Game
3. Install Pygame
   pip install pygame
4. Run the game
   python snake_game.py
   🎯 Controls
   Key Action
   ⬆️ Up Move Up
   ⬇️ Down Move Down
   ⬅️ Left Move Left
   ➡️ Right Move Right
   R Restart after Game Over
